# Portable Agent BrainをこのAIに接続する

[English](connect-agent.md) | 日本語

まだ専用の接続手順がないAIへ、次のプロンプトを一度だけ渡してください。送る前に `<...>` の部分を実際のパスへ置き換えます。

初期設定と、許可した過去のチャットからのメモ作りも任せる場合は、代わりに[セットアップ用プロンプト](setup-and-import.ja.md)を使ってください。

---

このAIが、利用者共通の指示やルールを読み込むために現在正式に対応している方法を確認してください。Portable Agent Brainを接続しますが、利用者のメモ本文をその設定へコピーしないでください。

使用する場所:

- ソフト本体: `<PORTABLE_AGENT_BRAIN_PATH>`
- AIが共通で読む指示書: `<PORTABLE_AGENT_BRAIN_PATH>/adapters/external-brain.md`
- このAIから見えるメモの保存先: `<BRAIN_LIBRARY_PATH>`

要件:

1. 編集前に、実際に使われる利用者共通の設定方法と読み込みの優先順位を確認してください。ほかのAIと同じ仕組みだと決めつけないでください。
2. 既存の指示、hooks、権限、モデル設定、プロジェクトごとの設定をすべて残してください。ファイルを変更する前に、元へ戻せるバックアップを作ってください。
3. 外部のMarkdownを正式に読み込めるなら、その方法を優先してください。使えない場合は、共通の指示書を必要なときに読むための短い文章だけを、管理範囲がわかる目印付きで追加してください。指示書の本文やメモを複製しないでください。
4. 保存先は `BRAIN_LIBRARY` またはCLIの `--library` で指定してください。このAIが実行される環境、コンテナ、sandboxから見えるパスを使い、ホストのホームフォルダがそのまま見えるとは考えないでください。
5. 保存先を最初から読み込んだり、prompt内へ索引を埋め込んだり、再帰的に全ファイルを読んだりしないでください。過去の知識が結果に影響する作業だけで検索してください。
6. このAIが安全な作業終了時hookに対応している場合、Portable Agent Brainの結果マーカーだけを確認し、なければ同じAIへ一度だけ判断を促すhookを提案してください。会話を読み取って保存する、別のAIを呼ぶ、メモを直接書くhookにはしないでください。正確な変更内容を見せずに導入しないでください。
7. 再度設定しても、参照、目印付きの文章、hookを重複させないでください。
8. 新しいセッションで、過去のメモが必要な作業では範囲を絞った `brain context` を使え、明らかな誤字修正では検索を省けることを確認してください。メモ本文や、関係のない共通設定が変わっていないことも確かめてください。
9. 変更したファイル、バックアップの場所、確認結果、元に戻す正確な手順を報告してください。正式な共通設定の方法を確認できない場合は、推測で編集せず、不明な点を説明して止まってください。

接続を簡単にするためという理由で、Portable Agent Brain本体、メモの保存先、既存プロジェクトを変更しないでください。
