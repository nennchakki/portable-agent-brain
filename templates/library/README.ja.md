# 自分のメモの保存先

[English](README.md) | 日本語

ここが、自分のメモの置き場です。この非公開フォルダには、複数のAIで共有するメモの原本を保存します。公開ソフトとは別のリポジトリにしてください。

新しい保存先は、意図的に空の状態で始まります。

```text
Projects: 0
Lessons: 0
Decisions: 0
Preferences: 0
Procedures: 0
Candidates: 0
```

`TEMPLATE.md` と `.gitkeep` は保存済みのメモではありません。書式見本をコピーして名前を変更するときは、ID、日付、対象範囲、根拠の見本をすべて実際の内容へ置き換えてください。会話原文、ツールの全記録、セッションID、認証情報は保存しません。

Markdownの本文と、先頭にあるYAMLの項目が原本です。必要ならObsidianで読み書きできます。HTML、検索用の索引、リンクの図は、この原本から作る表示です。
