Commands, JSON and YAML field names, working `TEMPLATE.md` files, and the demo
graph nodes are shared data, not separate translated copies. Their
explanatory guides and READMEs are available in both languages. Keep command
names and data keys as written when following either version.

The Japanese adapter is a reference translation for people. Agent connections
still use the same English `adapters/external-brain.md` file; selecting a
Japanese guide does not change that connection.
